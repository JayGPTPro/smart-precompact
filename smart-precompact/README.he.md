# Smart PreCompact

הפקודה: `/smart-precompact`

סקיל ל-Claude Code שמנהל את כל מה שקורה סביב `/compact`: מזהה מתי הקונטקסט מתמלא, מכין קומפאקט חכם ששומר את מה שחשוב, ומחזיר את ההקשר אוטומטית אחרי. הוא לא מחליף את `/compact`, ואתה ממשיך לעבוד ב-Claude Code כרגיל.

סקיל עצמאי של JayGPTPro. לא מוצר של Anthropic, ולא קשור לאירוע ה-hook הרשמי `PreCompact`.

בפירוט: הוא קורא את השיחה, מסנן את מה שחייב
לשרוד, ונותן לך שורת `/compact` עם הוראות שמותאמות לשיחה הזו, ופרומפט המשך לרגע שאחרי.
אופציונלי: hook שמזכיר לך בזמן, ומחזיר את ההקשר לבד אחרי הקומפאקט.
חדש: Mod ל-Claude Code. פס מעל שורת הכתיבה מראה כמה הקונטקסט מלא, והכפתור Smart compact שבו מכין את השורה ומקמפקט בלחיצה אחת.


**בכל שפה.** הסקיל עונה בשפה שבה כותבים לו. ההוראות הפנימיות שלו באנגלית, וזה לא משנה כלום בשימוש.

## למה

הקומפאקט הרגיל מסכם את כל השיחה, בלי לדעת מה הכי חשוב לך. בסיכום כזה דווקא הפרטים
הקטנים עלולים להיבלע: למה החלטתם, מה כבר נכשל, מה ביקשת, ונוסח מדויק של שגיאות. ואז
Claude מנסה שוב גישה שכבר נפסלה, או שואל שאלה שכבר ענית עליה. הסקיל אומר לסיכום מה
אסור לאבד, שומר את ההמשך בקובץ, ומחזיר אותו לשיחה אחרי הקומפאקט.

## מה מקבלים

```text
/compact שמור: למה נפסל רקע המטבח בתמונה הראשית (אמזון דורשת רקע לבן), למה
תמונה 2 היא אינפוגרפיקת מידות (אצל המתחרים מתלוננים שהמוצר קטן מהצפוי), והבקשה של
המשתמש: "לא לשנות את הכותרת. עובדים רק על התמונות". אפשר לדחוס את סבבי הניסוח.
```

```text
המשך מאיפה שעצרנו.

בונים: סט תמונות לליסטינג באמזון של בקבוק מים מתקפל.
מצב: התמונה הראשית מוכנה, על רקע לבן. תמונות 2 עד 7 עוד לא נוצרו.
החלטות: תמונה 2 היא אינפוגרפיקת מידות, כי אצל המתחרים מתלוננים שהמוצר קטן מהצפוי.
נכשל, אל תנסה שוב: רקע של מטבח בתמונה הראשית (אמזון דורשת רקע לבן).
חוקים שנקבעו: לא לשנות את הכותרת. עובדים רק על התמונות.
הבא בתור: 1) אינפוגרפיקת המידות  2) תמונה בשימוש בטיול  3) להראות לי לפני שממשיכים.
```

## התקנה

### הדרך הקלה: Claude מתקין
1. חלץ את ה-zip. תקבל תיקייה בשם `smart-precompact`.
2. גרור אותה לתיקיית פרויקט כלשהי שבה פתוח Claude Code.
3. הדבק ל-Claude את התוכן של `install-prompt.he.txt`. הוא מעתיק את הסקיל, שואל אם להוסיף
   את ה-hook, ובודק שהכל עובד.

### ידנית
1. העתק את התיקייה ל-`~/.claude/skills/smart-precompact/`
   (בווינדוס: `%USERPROFILE%\.claude\skills\smart-precompact\`).
2. פתח סשן חדש של Claude Code והקלד `/smart-precompact`.

**עדכון גרסה:** אם כבר מותקנת גרסה קודמת, שמור את `config.md` שלך מחוץ ל-`~/.claude/skills`
לפני ההעתקה, והחזר אותו אחריה. ההגדרות שלך נמצאות שם, והרצה חוזרת של `npx skills add` מחליפה
את כל התיקייה, כולל `config.md`. אל תשאיר עותק גיבוי של תיקיית הסקיל בתוך `~/.claude/skills`:
Claude Code יטען את ה-Mod מהגיבוי במקום מהגרסה החדשה.

## שימוש

| מה כותבים | מה קורה |
|---|---|
| `/smart-precompact` | הבלוקים להדבקה. לא נכתב כלום לדיסק |
| `/smart-precompact handoff` | גם שומר את פרומפט ההמשך ב-`~/.claude/handoffs/`, כדי שסשן חדש יוכל להמשיך ממנו |
| `/smart-precompact save` | גם מוסיף החלטות ומשימות ל-`docs/DECISIONS.md` ול-`docs/TASKS.md`, אם הם כבר קיימים בפרויקט |
| `/smart-precompact save notes` | כמו `save`, ובנוסף כותב לתיקיית הפתקים שלך (Obsidian וכדומה). את הנתיב מגדירים ב-`config.md` |
| **Smart compact** בפס | מכין את השורה ברקע ומקמפקט, בלחיצה אחת (ראה "הפס") |

אפשר גם לכתוב במילים: "תכין אותי לקומפאקט", או "תכין לקומפאקט ותשמור" בשביל `handoff`.

**סודות:** מפתחות, טוקנים וסיסמאות שעלו בשיחה מוחלפים ב-`[REDACTED]` לפני שהם נכנסים
לבלוק או לקובץ.

## הפס (Mod)

בתיקיית הסקיל יש גם Mod ל-Claude Code. Claude Code טוען אותו לבד בכל סשן חדש, בלי שום התקנה,
ומציג שורה אחת מעל שורת הכתיבה:

- **כמה הקונטקסט מלא**, באחוזים ובפס. ב-80% (70% בחלון של 200 אלף טוקנים) הוא נצבע באדום.
- **איפה הדברים עומדים:** `ready` (עוד לא הוכנה שורה), `prepared` (הסקיל הכין אחת), `Claude is working`.
- **כמה עלה הסשן** וכמה ממגבלת 5 השעות נוצל, בחלון רחב.
- **Smart compact:** לחיצה אחת. אם הסקיל הכין שורה ב-15 הדקות האחרונות, הוא משתמש בה.
  אחרת הוא קודם מכין אחת ברקע, וזו קריאה נוספת אחת למודל על כל השיחה, ואז מקמפקט איתה.
- **Hide:** מסתיר את הפס עד הסף הבא (50% ו-70% בחלון של 200 אלף, 60% ו-80% במיליון).
  אחרי הסף האחרון הוא נשאר מוסתר עד הקומפאקט הבא.

אחרי קומפאקט הפס מציג קבלה, למשל `✓ Compacted 512k → 41k · 471k lighter`, עד שלוחצים OK.
כשהפס טעון, כל קומפאקט שאין לו הוראות משלו, כולל האוטומטי, מקבל את השורה המוכנה, או רשימה
כללית של מה לשמור כשאין שורה.

הפס עצמו באנגלית.

**אין פס?** הגרסה שלך של Claude Code עוד לא מריצה Mods. הסקיל וה-hook עובדים אותו דבר גם בלעדיו.
**כיבוי הפס** בלי להסיר את הסקיל:

```bash
claude plugin disable smart-precompact-mod@skills-dir
```

## ה-hook (אופציונלי, מומלץ)

ה-hook (סקריפט Python) לא מריץ את הקומפאקט בשבילך. הוא עושה שני דברים:

1. **מזכיר בזמן.** בכל הודעה שאתה שולח הוא בודק כמה הקונטקסט מלא. ב-60% Claude קודם
   עונה לך כרגיל, ובסוף התשובה מכין לך את שורת ה-compact ושומר את פרומפט ההמשך לקובץ.
   ב-80% הוא מכין אותם שוב ואומר לך שזה הזמן.
2. **מחזיר את ההקשר.** מיד אחרי קומפאקט, ידני או אוטומטי, הוא מחזיר לשיחה את קובץ
   ההמשך. אתה רק לוחץ Smart compact, או מעתיק את שורת ה-compact המוכנה ושולח אותה. ואם פספסת והקומפאקט האוטומטי רץ לבד,
   ההקשר מהפעם האחרונה שהסקיל רץ חוזר בכל זאת.

במודלים עם חלון קטן (200 אלף טוקנים) הספים נמוכים יותר: 50% ו-70%.

**התקנה:**

```bash
python3 ~/.claude/skills/smart-precompact/scripts/install_hook.py
```

הסקריפט שומר גיבוי של `~/.claude/settings.json`, מוסיף את ה-hook בלי לגעת ב-hooks
אחרים, ובודק שהקובץ תקין. בווינדוס כתוב `python` במקום `python3`.

**בדיקה שהוא עובד:**

```bash
python3 ~/.claude/skills/smart-precompact/scripts/compact_hook.py --test
```

שלח הודעה כלשהי ב-Claude Code. בתשובה Claude יגיד שה-hook עובד, ויכתוב כמה הקונטקסט
מלא כרגע ומה גודל החלון שה-hook מניח. אם המספר לא דומה למה שמוצג אצלך, ראה "מגבלות".
אם לא קורה כלום, פתח סשן חדש (הגדרות נטענות בתחילת סשן).
הפס קורא את הספירה של Claude Code עצמו, ולכן האחוז שלו יכול להיות קצת שונה מזה של ה-hook.

**הסרה של ה-hook בלבד:**

```bash
python3 ~/.claude/skills/smart-precompact/scripts/install_hook.py --uninstall
```

**שינוי הספים:** בשורות `THRESHOLDS` בראש `scripts/compact_hook.py`.

**מה נשמר במחשב:** ה-hook קורא מקובץ השיחה המקומי רק את מספרי הטוקנים. הסקיל כותב
קובץ המשך קטן אחד לכל שיחה ב-`~/.claude/handoffs/` (עד כ-200 מילה: מה בונים, מה הוחלט,
מה נכשל ומה ביקשת), וה-hook שומר לידו קובץ מצב בלי תוכן מהשיחה. הפס שומר ב-`~/.claude/handoffs/.state/` שני יומנים
קטנים של הקומפאקט האחרון שלו (זמנים ומספרי טוקנים, בלי תוכן מהשיחה), וסכום מצטבר של הטוקנים שחסך. באותה שיחה קובץ ההמשך
נדרס בכל שמירה, וה-hook מוחק קובץ המשך שלא נגעו בו 14 יום. הוא מוחק רק קבצים שהסקיל כתב, ואף פעם לא
את הקובץ של השיחה הנוכחית או קובץ שמוזכר בהודעה שלך.
אין שרת ואין שליחה לשום יעד חדש: אחרי הקומפאקט ההמשך חוזר לשיחה עם Claude, כמו כל
הודעה אחרת בה. לתוך הפרויקט נכתב משהו רק אם ביקשת `save` במפורש.

## מגבלות

- **Claude לא יכול להריץ `/compact` בעצמו.** הוא מכין את השורה, ואתה שולח אותה. או לוחץ Smart compact
  בפס, שעושה את שניהם בלחיצה אחת.
- **ה-hook נדלק רק כשאתה שולח הודעה.** אם Claude עובד לבד במשימה ארוכה, ההערה תגיע
  עם ההודעה הבאה שלך.
- **סשן חדש לא יודע על קובץ ההמשך לבד.** מדביקים לו את המשפט מהבלוק השלישי. עם ה-hook
  הקובץ נשמר 14 יום מהפעם האחרונה שנכתב. לטווח ארוך יותר, `save`.
- **גודל החלון מנוחש לפי שם המודל.** Opus 4.7 ומעלה, Sonnet 5 ומעלה ו-Fable: מיליון
  טוקנים. השאר: 200 אלף. עובדים דרך Bedrock, Vertex או gateway עם חלון אחר? הגדר
  `CLAUDE_CODE_MAX_CONTEXT_TOKENS` לגודל הנכון.
- **ה-hook דורש Python 3.8 ומעלה.** נבדק על macOS. בווינדוס ובלינוקס עוד לא נבדק בפועל.

## הסרה מלאה

```bash
python3 ~/.claude/skills/smart-precompact/scripts/install_hook.py --uninstall
```

ב-`~/.claude/handoffs/`, ובלי ה-hook הם כבר לא נמחקים לבד. אפשר למחוק את התיקייה.
