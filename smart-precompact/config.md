# Personal settings for smart-precompact

This is the only place the skill reads personal settings from.
You can leave everything empty: the skill works fully, except for `save notes`.

## Notes folder (for `save notes`)

The full path to your notes folder (Obsidian or any other Markdown folder).

## Subfolder names inside the notes folder

If your folders are named differently, change them here. A folder that does not exist on disk simply does not get written to.

daily_logs: Daily Logs
decisions: Decisions
people: People
business: Business
preferences: Preferences
